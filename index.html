🎓 Zadania dla studentów

Poziom 1 — Podstawy: wpisywanie, kliknięcie i odczyt
  1. Otwórz stronę przy użyciu Use Application/Browser.
  2. Wpisz imię przez Type Into.
  3. Wybierz miesiąc urodzenia przez Select Item (lub Click).
  4. Kliknij Wygeneruj imię jednorożca.
  5. Odczytaj element unicornName aktywnością Get Text i pokaż wynik w Message Box.
Poziom 2 — Walidacja i Check App State
  1. Kliknij generowanie przy pustym polu imienia i sprawdź komunikat.
  2. Wykryj komunikat przez Check App State.
  3. Wprowadź poprawne dane i użyj Check App State do sprawdzenia, czy wynik się pojawił.
  4. Kliknij Wyczyść i sprawdź, czy wynik zniknął.
Poziom 3 — For Each i Excel
  1. Przygotuj listę 5 imion i miesięcy urodzenia.
  2. Przejdź pętlą po liście, wypełnij formularz, wygeneruj i odczytaj każdy wynik.
  3. Zbierz imiona, miesiące i wygenerowane nazwy w DataTable.
  4. Zapisz DataTable do pliku Excel.
