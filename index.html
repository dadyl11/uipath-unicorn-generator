🎓 Student practice tasks

Level 1 — Basics: input, click and read
  1. Open this page using Use Application/Browser.
  2. Enter a first name using Type Into.
  3. Choose a birth month using Select Item (or Click).
  4. Click Generate unicorn name.
  5. Read unicornName using Get Text and show the value in a Message Box.
Level 2 — Validation and Check App State
  1. Click Generate with the name field empty and observe the message.
  2. Handle the warning with Check App State.
  3. Fill valid data and use Check App State to verify that the result appeared.
  4. Use Reset and verify that the result disappears.
Level 3 — For Each and Excel
  1. Create a list of 5 first names and birth months.
  2. Loop through the list, populate the form, generate and read each result.
  3. Collect original names, months and generated results in a DataTable.
  4. Write the DataTable into an Excel file.
Educational demo • Runs locally • No external dependencies • No data is transmitted
